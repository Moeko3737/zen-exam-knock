# zen-exam-knock

ZEN大学の試験対策を目的とした、Webブラウザ上で利用できるクイズ形式の学習アプリです。

PythonとWebアプリケーション開発の授業内容を、問題演習を通して復習できるサイトを目指しています。

## 概要

各科目は全15回の授業内容に対応し、各回20〜30問の問題を収録しています。

単純に問題を解くだけでなく、学習目的に応じて複数の出題モードを利用できるようにします。

## 実装予定の機能

* 授業回を指定して20問に挑戦
* 全範囲からランダムに出題
* 100問ノック
* 間違えた問題の復習
* 正誤判定
* 問題ごとの解説表示
* 学習結果の表示
